# 角色设计

## 1. 概述

角色设计定义了 AI 故事游戏中的角色体系，包括系统固定角色和用户可配置角色。

## 2. 角色类型

| 类型 | 说明 |
|------|------|
| `player` | 用户角色（每 world 唯一） |
| `narrator` | 旁白角色（每 world 唯一） |
| `npc` | 非玩家角色（章节/事件动态加入） |

## 3. 固定系统角色

### 3.1 用户角色 (player)

- 每 world 唯一
- 由用户控制
- 可携带装备、道具、技能

### 3.2 旁白角色 (narrator)

- 每 world 唯一
- 用于环境描述、旁白叙述
- 可走 T0 模板直出模式

### 3.3 万能角色

用于路人起哄、功能性推进等场景。

## 5. 游玩中的角色表

### 5.1 表结构

```sql
CREATE TABLE t_game_run_parameter (
  id INTEGER PRIMARY KEY,
  game_run_id INTEGER,
  parameter_id INTEGER,
  parameterCardJson TEXT,
  ...
);
```

### 5.2 用途

存储游玩过程中的角色参数值变化，每个用户游玩同一角色会产生不同的游玩数据。

## 6. 角色静态摘要缓存

每个角色提前生成 `roleLiteProfile`：

```json
{
  "name": "萧炎",
  "roleType": "npc",
  "traits": ["隐忍", "少年天才跌落谷底", "重尊严"],
  "speechStyle": "压抑、克制、偶尔锋利"
}
```

发言时直接取用，不再每轮重新压参数卡。

## 7. 角色关系

### 7.1 关系类型

- 好感度
- 信任度
- 敌对度
- 阵营

### 7.2 关系变化

狼人杀等小游戏结束后，根据表现调整角色关系：
- 发言、投票、是否"站队"
- 胜利/失败奖励

## 8. 角色发言风格

### 8.1 NPC 发言参数

```json
{
  "logic": "30~80",
  "aggressive": "20~80",
  "trust_player": "-30~30",
  "lie_skill": "10~90"
}
```

### 8.2 发言风格约束

- 旁白：第三人称叙述，简洁有力
- NPC：根据性格参数卡生成符合人设的台词
- 用户：直接使用用户输入

## 9. 角色解锁

通过触发器可以解锁新角色：

```typescript
// 触发器动作类型
- unlock_role     // 解锁角色
```

## 10. 与其他模块的关系

- **NarrativeOrchestrator**：决定谁发言
- **MiniGameController**：小游戏参与角色
- **TriggerEngine**：角色解锁触发器
- **SpeakerRouteEngine**：发言路由
