## 本地大模型
推荐使用 Qwen3-0.6B

|模型|参数量|模型类型| 适用场景               |推荐理由
|---|---|---|--------------------|---|
|Qwen3-0.6B|0.6B|文本生成| （任务/剧情/系统命令）       | 轻量级模型，适合本地 CPU    |
|moka-ai/m3e-small|300M|嵌入匹配| 基础意图分类（任务/剧情/系统命令） |轻量级模型，适合本地 CPU|
|Qwen2.5-1.5B|1.5B|文本生成| 基础意图分类（任务/剧情/系统命令） | 极快，本地 CPU 也能跑    |
|Qwen2.5-3B|3B|文本生成| 中等复杂度意图 + 槽位提取     | 平衡速度和精度           |
|Qwen2.5-7B|7B|文本生成| 复杂意图推理、多意图分离       | 需要较强本地 GPU         |

### moka-ai/m3e-small
moka-ai/m3e-small 是**文本嵌入模型（Embedding Model）**，不是生成式模型（Instruct/Chat Model）。
m3e-small 不能直接用来做意图分析——它不会输出"创建任务"这样的标签。但可以用间接方式实现意图分类：

方案：嵌入 + 向量相似度匹配
用户输入 → m3e-small 编码 → 768维向量
                              ↓
                    与预定义意图向量计算余弦相似度
                              ↓
                    取最高相似度的意图作为分类结果

优点
极轻量：24M 参数，推理几乎无延迟，CPU 就能跑
确定性：不像生成模型可能输出格式不稳定
适合的场景：意图类别有限（创建/退出/查询/正常对话），不需要复杂推理
缺点
需要手动维护意图描述文本库
对复杂/模糊意图区分能力弱
新增意图需要重新编码向量

| | m3e-small (嵌入匹配) | Qwen2.5-1.5B (生成分类)          |
|---|---|------------------------------|
| 模型大小 | ~90MB | ~1.5GB                       |
| 推理速度 | 极快（<10ms） | 快（~100ms）                    |
| 模型类型 | 文本嵌入模型 (Embedding Model) | 生成式模型 (Instruct/Chat Model/Causal LLM) |
| 分类准确度 | 中等（简单场景够用） | 较高                           |
| 灵活性 | 低（需预定义意图） | 高（可处理未见意图）                   |
| 输出可控性 | 高（向量匹配确定性强） | 中（需约束输出格式）                   |
| 部署复杂度 | 低 | 中                            |
