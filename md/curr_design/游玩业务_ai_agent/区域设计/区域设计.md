# 发言聚焦系统（原名：区域设计）

## 定位

**不是地图系统，而是发言过滤器。**

核心目标只有一个：用最小的状态，控制当前剧情轮次中哪些角色可以被剧情编排师选中发言。

---

## 核心原则

1. **区域不是地图** — 不模拟坐标、路径、导航
2. **区域不是场景** — 不对应具体物理位置，而是叙事上下文分组
3. **区域只影响发言权** — 决定谁有资格说话，不决定谁能听见谁
4. **轻量优先** — 状态越少越好，维护成本越低越好

---

## 数据模型

只维护一个运行时状态对象：

```json
{
  "当前发言上下文": {
    "主区域": "诡异学校-教室",
    "激活角色列表": ["林小茹", "李老师"],
    "远程可发言角色": [],
    "本次例外角色": []
  }
}
```

字段说明：

| 字段 | 说明 | 示例 |
|---|---|---|
| 主区域 | 当前叙事聚焦的大区域 | "诡异学校-教室" |
| 激活角色列表 | 当前默认可以参与发言的角色 | ["林小茹", "李老师"] |
| 远程可发言角色 | 不在场但因剧情需要可以发言的角色 | ["电话里的声音"] |
| 本次例外角色 | 单次剧情需要强制加入的非激活角色 | [] |

---

## 区域划分原则

区域名称采用「地点-细分」格式，两层足够：

```
诡异学校
  └ 诡异学校-教室
  └ 诡异学校-天台
  └ 诡异学校-走廊

阴间
  └ 阴间-奈何桥
  └ 阴间-忘川河
```

不需要三层嵌套。如需更细的区分，通过「当前发言上下文.激活角色列表」直接控制。

---

## 维护规则

### 谁来维护？

- **记忆管理器**：负责维护当前区域状态，并在每次剧情轮次开始时同步给编排 Agent
- **意图分析师**：在识别到移动意图时，更新「主区域」和「激活角色列表」

### 何时更新？

| 触发时机 | 更新内容 |
|---|---|
| 用户明确说要移动 | 更新主区域 + 激活角色列表（根据新区域的角色配置） |
| 章节切换 | 重置激活角色列表（按新章节的开场角色配置） |
| 剧情事件触发 | 意图分析师决定是否加入「远程可发言角色」或「本次例外角色」 |
| 任务阶段切换 | 任务剧情编排师决定是否更新上下文 |

### 更新流程

```
用户输入
  ↓
意图分析师识别移动意图 / 区域变化意图
  ↓
记忆管理器更新「当前发言上下文」
  ↓
同步给：剧情编排师、角色发言器、任务剧情编排师、任务角色发言器
```

---

## 与其他系统的关系

### 与「剧情编排师」的关系

剧情编排师在选择下一个发言角色时，必须从「当前发言上下文.激活角色列表」中选取。

如果编排师判断某个角色需要发言，但该角色不在激活列表中，需要通过「本次例外角色」临时加入。

### 与「记忆管理器」的关系

记忆管理器维护「当前发言上下文」状态，并在历史记忆中记录区域切换事件（格式：`[场景切换] 从 A 移动到 B`）。

### 与「章节阶段推进」的关系

章节切换时，激活角色列表由章节内容中的「开场角色配置」决定，不需要继承上一章的状态。

### 与「任务系统」的关系

任务系统有自己的发言上下文管理，不依赖全局的区域状态。任务结束后，回归全局区域上下文。

---

## 默认规则

1. **故事开始时**：激活角色列表 = 章节开场配置的所有角色
2. **角色跨区域移动时**：旧区域角色默认移出激活列表，新区域角色默认加入
3. **远程发言**：必须由意图分析师或剧情编排师显式加入「远程可发言角色」
4. **例外发言**：单次生效，剧情轮次结束后自动清除，不保留到下一轮

---

## 简化决策

以下问题在当前设计中**不处理**：

| 不处理的问题 | 原因 |
|---|---|
| 角色移动路径 | 不做地图模拟 |
| 区域连接关系（通道、传送门） | 移动触发由意图识别决定，不需要提前定义连接 |
| 谁能听见谁 | 发言过滤器不处理听觉逻辑 |
| 动态发现新区域 | 第一版只做静态区域配置 |
| 区域嵌套超过两层 | 用「主区域-子区域」两层足够 |
| NPC 自动移动 | NPC 移动由剧情编排师决定，不做独立 AI |

---

## 消息同步格式

记忆管理器向各 Agent 同步区域状态时，使用统一格式：

```
【当前发言上下文】
主区域：{主区域名称}
激活角色：{激活角色列表.join('、')}
远程可发言：{远程可发言角色列表.join('、') || '无'}
例外角色：{本次例外角色列表.join('、') || '无'}
```

---

## 总结

发言聚焦系统 = 最小化的「谁可以说话」状态

它的价值在于：防止 AI 叙事时所有角色同时发言、场面失控。

它不负责地图、不负责寻路、不负责空间逻辑。只在每个剧情轮次开始时，告诉编排师：「现在让谁说话是合理的。」
