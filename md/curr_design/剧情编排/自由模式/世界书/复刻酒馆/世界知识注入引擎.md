## <条目标题>

- **Keys（关键词）**: `["关键词1", "关键词2", "/正则/"]`
- **Constant（常驻）**: `false`
- **Probability（概率%）**: `100`
- **Order（插入顺序）**: `100`
- **Group（互斥组）**: `null`
- **Selective Logic**: `null`
- **Content（正文）**:

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `Keys` | 是（Constant 条目除外） | 逗号分隔。纯文本默认不区分大小写；用 `/.../` 包裹视为 JS 正则 |
| `Constant` | 否 | `true` 表示常驻，每次都注入；不写或 `false` 表示关键词触发 |
| `Probability` | 否 | 0~100，触发后再加一层概率（用于随机事件）；默认 100 |
| `Order` | 是 | 数字越大越靠后注入；常驻条目建议 10000+ |
| `Group` | 否 | 同组多条同时触发时，按 Group Weight 随机只留一条 |
| `Selective Logic` | 否 | `AND ANY` / `AND ALL` / `NOT ANY` / `NOT ALL` |
| `Content` | 是 | 注入到 AI 上下文的正文，必须自描述 |

## 字段填入规则

### `title`

- **类型**：string
- **必填**：是
- **规则**：条目的显示名称，人类可读。对应 MD 文件中的 `## 标题`
- **示例**：`"灵石经济体系"`、`"纯小白（主角）"`

---

### `category`

- **类型**：string
- **必填**：是
- **可选值**（9 个）：

| 值 | 含义 |  典型用途 |
|---|---|--|
| `constants` | 常驻条目 | 世界总纲、金手指规则、等级体系等每轮必注入的"宪法层" |
| `system` | 系统规则 |  经济体系、突破机制、任务奖励等修仙界运行机制 |
| `world` | 世界宏观 |  地理格局、势力关系网、时间流逝 |
| `locations` | 地点 |  黑风寨、后山秘境、山脚小镇等具体地点 |
| `characters` | 角色 |  纯小白、红缥缈、白锦儿等 NPC/主角 |
| `factions` | 势力 |  黑风寨（势力）、圣地、宗门、魔修势力 |
| `items` | 物品 | 神秘小塔、大砍刀、青云诀等 |
| `events` | 事件 | 殿主失踪、栽赃陷害、武脉觉醒等主线/伏笔 |
| `random` | 随机事件 |  神秘商人、黑气预警等概率触发的氛围事件 |

**由 MD 文件名自动决定**，不需要手动填。

---

### `keys`

- **类型**：`string[]`（字符串数组）
- **必填**：`constant: true` 时可空数组 `[]`；`constant: false` 时必须有至少一个关键词
- **填入规则**：
  - 纯文本关键词：不区分大小写，逗号分隔
  - 正则表达式：用 `/pattern/flags` 格式包裹
  - 中文不需要整词匹配（`matchWholeWords` 全局设为 `false`）
- **示例**：

```json
// 纯文本
"keys": ["黑风寨", "山寨", "大当家"]

// 带正则
"keys": ["铁匠铺", "/老王|铁匠/"]

// 常驻条目（空数组）
"keys": []
```


---

### `constant`

- **类型**：boolean
- **必填**：否（默认 `false`）
- **规则**：
  - `true` = 每轮对话都注入，不依赖关键词扫描
  - `false` = 需要关键词命中才激活
- **建议**：只有世界总纲、核心系统规则设为 `true`，其余全部 `false`

---

### `probability`

- **类型**：number（整数 0-100）
- **必填**：否（默认 100）
- **规则**：关键词命中（或 constant=true）后，再过一层概率筛
  - `100` = 必定注入
  - `0` = 等于禁用（用于"前期不激活，后期改 100"的角色）
  - `30` = 30% 概率注入（控制神秘感/稀有度）
- **典型用法**：
  - 后期角色前期禁用：`"probability": 0`
  - 伏笔角色保持神秘：`"probability": 30`
  - 随机事件防滥用：`"probability": 20`

---

### `order`

- **类型**：number（整数）
- **必填**：是
- **规则**：数字越大，在注入的上下文中越靠后（越接近 AI 的注意力焦点）。token 预算不够时，按 order 升序截断（小的先丢）
- **分层建议**：

| 范围 | 用途 |
|------|------|
| 10000+ | 常驻条目（世界总纲/系统规则） |
| 9000+ | 系统级常驻（经济/突破/金手指体系） |
| 150-180 | 世界宏观（地理/势力/时间） |
| 200-240 | 地点 |
| 250-280 | 势力 |
| 300-380 | 角色 |
| 400-430 | 物品 |
| 500-530 | 事件/阴谋 |
| 600-630 | 随机事件 |

---

### `group`

- **类型**：`string | null`
- **必填**：否（默认 `null`）
- **规则**：同组多条同时命中时，只留一条（按 weight 随机或按 order 最大值胜出）
- **示例**：`"group": "weather_events"` 表示天气类事件互斥，同轮只触发一个
- **典型用法**：多个变体描述同一场景，只需要一个出现

---

### `selectiveLogic`

- **类型**：`string | null`
- **必填**：否（默认 `null`）
- **可选值**：

| 值 | 含义 |
|---|---|
| `null` | 不使用选择性逻辑，主 key 命中即激活 |
| `"AND ANY"` | 主 key 命中 **且** selectiveKeys 中任意一个也命中 |
| `"AND ALL"` | 主 key 命中 **且** selectiveKeys 中全部都命中 |
| `"NOT ANY"` | 主 key 命中 **且** selectiveKeys 中没有任何一个命中 |
| `"NOT ALL"` | 主 key 命中 **且** selectiveKeys 中不是全部都命中（至少缺一个） |

---

### `selectiveKeys`

- **类型**：`string[] | null`
- **必填**：否（默认 `null`）
- **规则**：配合 `selectiveLogic` 使用的二级关键词。格式同 `keys`
- **示例**：

```json
"selectiveLogic": "AND ANY",
"selectiveKeys": ["筑基", "火系", "感情"]
```
表示：主 key 命中且"筑基"或"火系"或"感情"也出现在对话中时才激活

---

### `content`

- **类型**：string
- **必填**：是
- **规则**：
  - 激活后注入到 AI 上下文的正文
  - **必须独立自描述**--因为 `keys`/`title` 不进入上下文，只有 `content` 会被 AI 看到
  - 推荐用 `[条目名]` 开头，让 AI 知道这段信息的指代对象
  - 用 `\n` 换行，保持简洁
- **示例**：

```json
"content": "[黑风寨] 主角的山寨根据地，位于某处山头。\n表面是普通土匪窝，寨门挂着\"替天行道\"的旗帜。\n核心设施：聚义厅（议事）、宿舍区、训练场、库房。"
```

---

### `id`

- **类型**：string
- **必填**：自动生成，不需要手动填
- **格式**：`entry_{序号}_{category}`，如 `entry_006_system`

---
