# 模型配置设计

## 1. 概述

AI 故事系统的模型配置必须与 AI 漫剧完全隔离，独立配置编排师、记忆管理、文本模型、图片模型、语音模型等。

## 2. 配置结构

### 2.1 AI 故事模型配置

| 配置项 | 说明 | 模型类型 |
|--------|------|---------|
| 编排师 | 剧情编排、角色轮次、分支推进 | 文本模型 |
| 记忆管理 | 记忆抽取、短/中/长期记忆 | 文本模型 |
| 章节判定 | 章节结束条件与章节点切换 | 文本模型 |
| 小游戏控制 | 小游戏局内逻辑和状态 | 文本模型 |
| 安全审查 | 越权、注入、人设漂移检查 | 文本模型 |
| AI 生图 | 图片生成 | 图片模型 |
| 语音生成 | 文本转语音 | 语音模型 |
| 语音识别 | 语音转文本 | 语音模型 |
| 语音设计 | 音色克隆 | 语音模型 |

### 2.2 配置界面

参考 AI 漫剧的设置页面，提供：
- API 地址配置
- 模型配置（完全独立于 AI 漫剧）
- 提示词配置（只有 admin 账号可以编辑）

## 3. 提示词配置

### 3.1 提示词代码

为 AI 故事单独定义以下 prompt code：

| Code | 名称 | 职责 |
|------|------|------|
| `story-main` | 主调度 | 总入口和工具选择 |
| `story-orchestrator` | 剧情编排 | 本轮台词、动作、分支生成 |
| `story-memory` | 记忆抽取 | 短/中/长期记忆整理 |
| `story-chapter` | 章节判定 | 结束条件与章节点切换 |
| `story-mini-game` | 小游戏控制 | 局内规则与状态更新 |
| `story-safety` | 安全审查 | 越权、注入、人设漂移检查 |

### 3.2 配置状态

| 状态 | 说明 |
|------|------|
| 默认值 | 使用系统预设提示词 |
| 自定义 | 用户自定义的提示词 |

### 3.3 操作按钮

- **重置提示词**：恢复为默认值
- **保存**：保存自定义提示词

### 3.4 状态提示

- 默认值状态：`*当前使用默认提示词，编辑后将保存为自定义值`
- 自定义状态：`*当前使用自定义提示词，点击重置将恢复默认值`

## 4. 模型 Key 配置

建议配套的模型 key 单独区分：

| Key | 说明 |
|-----|------|
| `storyAgent` | 主编排 agent |
| `storyMemoryAgent` | 记忆管理 agent |
| `storyChapterAgent` | 章节判定 agent |
| `storyMiniGameAgent` | 小游戏 agent |
| `storySafetyAgent` | 安全审查 agent |

## 5. Agent 架构

### 5.1 目录结构

```
src/
  agents/
    story/
      orchestrator/
      memory_manager/
      chapter_judge/
      mini_game/
      safety/
  story_runtime/
    prompts/
    templates/
    schemas/
    states/
    adapters/
```

### 5.2 Agent 职责

| Agent | 输入 | 输出 |
|-------|------|------|
| **编排师** | 快照、消息、记忆、章节规则、角色参数 | speaker、content、state_delta |
| **记忆管理** | 对话历史 | add/update/delete、summary、index_tags |
| **章节判定** | 章节条件、状态快照、任务进度 | should_end、result、next_chapter_id |
| **小游戏控制** | 游戏状态、用户输入 | round、phase、result、reward_delta |
| **安全审查** | 待落库内容 | status: ok/reject、reason |

### 5.3 调用链

```
1. 读取 game_run 当前快照
2. 拉取角色参数卡、章节配置、世界观配置
3. 交给 story_orchestrator 生成本轮剧情动作
4. 若触发记忆更新，再交给 memory_manager
5. 若达到章节边界，再交给 chapter_judge
6. 若触发小游戏，再切到 mini_game_agent
7. 最后把结果写回 snapshot/event/memory/summary
```

## 6. 编排师极简版

### 6.1 核心要求

- 只做一件事：决定本轮由谁发言，以及剧情推进一小步
- 不写台词、不写剧情正文
- 不复述章节或背景
- 每轮只推进一小步
- 返回结果要快速

### 6.2 输出格式

```json
{
  "role_type": "npc",
  "speaker": "萧炎",
  "motive": "继续挑衅萧家子弟",
  "await_user": false,
  "next_role_type": "player",
  "next_speaker": "用户",
  "trigger_memory_agent": false,
  "event_adjust_mode": "update",
  "event_status": "active",
  "event_summary": "萧炎挑衅萧家子弟",
  "event_facts": ["萧炎正在嘲讽", "用户需要回应"]
}
```

### 6.3 输入模板

```json
{
  "world": { "name": "", "intro": "" },
  "chapter": { "title": "", "directive": "", "opening": "" },
  "roles": [],
  "current_phase": { "label": "", "goal": "", "allowed_speakers": [] },
  "current_event": { "index": 1, "kind": "scene", "status": "active" },
  "turn_state": { "can_player_speak": false, "expected_role": "" },
  "recent_dialogue": "",
  "latest_player_message": ""
}
```

## 7. 速度优化策略

### 7.1 关键优化点

1. **关闭思考模式**：设置 `reasoning_effort: minimal`
2. **减少上下文**：只发送必要的精简信息
3. **JSON 转精炼文本**：不要发送 JSON 格式的角色参数
4. **异步处理**：记忆管理和语音生成异步执行

### 7.2 接口优化

- `/orchestration`：只返回 speaker 和 motive
- `/streamlines`：流式返回台词内容
- `/streamvoice`：流式返回语音

### 7.3 豆包模型参数

```json
{
  "model": "doubao-seed-2-0-lite-260215",
  "reasoning_effort": "minimal",
  "max_output_tokens": 131072
}
```

## 8. 状态边界

必须把这些状态分开：

| 状态层 | 内容 |
|--------|------|
| 静态内容 | 故事、章节、角色、世界观 |
| 动态运行 | 当前章节、当前场景、用户位置、关系值 |
| 局部模式 | 小游戏局内状态 |
| 记忆层 | 短期、中期、长期摘要 |
