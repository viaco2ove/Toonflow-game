# 语音模型预设

## 1. 概述

语音模型预设用于为故事中的角色配置音色。通过克隆音色实现兼容性和稳定性。

## 2. 音色预设

### 2.1 业务标准音色（6个）

通过克隆音色文件走语音生成接口：

| 音色名称 | 文件名 | 说明 |
|---------|--------|------|
| 标准男声 | `story_std_male.wav` | 通用男性声音 |
| 标准女声 | `story_std_female.wav` | 通用女性声音 |
| 温柔女声 | `story_gentle_female.wav` | 温柔的女性声音 |
| 活泼女声 | `story_lively_female.wav` | 活泼的女性声音 |
| 沉稳男声 | `story_steady_male.wav` | 沉稳的男性声音 |
| 讲述者音色 | `story_narrator.wav` | 旁白/叙述声音 |

### 2.2 音色选择逻辑

```
用户选择音色
    ↓
判断：用户和创作者使用相同模型？
    ↓ 是 → 走预设音色通道
    ↓ 否 → 走克隆音色生成通道
```

## 3. 模型选择

### 3.1 语音生成模型

| 模型 | 速度 | 情绪 | 成本 | 推荐场景 |
|------|------|------|------|---------|
| Qwen TTS Flash / Realtime | 最快 | 无 | 低 | 对话/实时交互 |
| CosyVoice v3 Flash | 中等 | 有 | 中 | 性价比优先 |
| CosyVoice v3 Plus | 偏慢 | 最丰富 | 高 | 高质量需求 |
| Sambert | 稳但不快 | 一般 | 最低 | 稳定优先 |

**推荐**：优先使用 `cosyvoice-v3-flash`

### 3.2 语音设计模型

用于生成克隆音色：

| 模型 | 说明 |
|------|------|
| Qwen Voice Design | `qwen-voice-design` → `qwen3-tts-vd-2026-01-26` |
| CosyVoice Clone | `voice-enrollment` → `cosyvoice-v3.5-plus` |

## 4. 边生成边播模式

### 4.1 流式 TTS + 边播

```
请求 TTS（流式）
    ↓
一边返回音频 chunk
    ↓
一边播放
```

**效果**：
- 首包：从 1-2秒 → 200-500ms
- 用户感觉：几乎秒开口

### 4.2 优化策略

#### 4.2.1 缓存音色 embedding

```
MP3 → embedding → 存缓存
之后直接用 embedding
```

#### 4.2.2 短句优先切分

按标点切分：
- `。！？` → 强切
- `，` → 不切
- 每段 20-40 字

#### 4.2.3 预热机制

提前调用一次空 TTS：
- GPU 预热
- 模型加载
- 首包减少 100-500ms

#### 4.2.4 音色连接复用

一次聊天会话长期保留：
```json
{
  "narrator": {
    "voice_id": "narrator",
    "voice_ref": "narrator.mp3",
    "clone_voice_id": "clone_xxx"
  },
  "girl": {
    "voice_id": "female_soft",
    "voice_ref": "female_soft.mp3",
    "clone_voice_id": "clone_yyy"
  },
  "boy": {
    "voice_id": "male_calm",
    "voice_ref": "male_calm.mp3",
    "clone_voice_id": "clone_zzz"
  }
}
```

## 5. 音色克隆接口

### 5.1 Qwen Voice Design

```json
{
  "model": "qwen-voice-design",
  "input": {
    "action": "create",
    "target_model": "qwen3-tts-vd-realtime-2026-01-15",
    "voice_prompt": "沉稳的中年男性播音员，音色低沉浑厚，富有磁性，语速平稳，吐字清晰，适合用于新闻播报或纪录片解说。",
    "preview_text": "各位听众朋友，大家好，欢迎收听晚间新闻。",
    "preferred_name": "announcer",
    "language": "zh"
  },
  "parameters": {
    "sample_rate": 24000,
    "response_format": "wav"
  }
}
```

### 5.2 CosyVoice Clone

```json
{
  "model": "voice-enrollment",
  "input": {
    "action": "create_voice",
    "target_model": "cosyvoice-v3.5-plus",
    "voice_prompt": "沉稳的中年男性播音员，音色低沉浑厚，富有磁性，语速平稳，吐字清晰，适合用于新闻播报或纪录片解说。",
    "preview_text": "各位听众朋友，大家好，欢迎收听晚间新闻。",
    "prefix": "announcer"
  },
  "parameters": {
    "sample_rate": 24000,
    "response_format": "wav"
  }
}
```

## 6. 混合音色

### 6.1 设计原则

不再走纯混合音色功能，而是混合后作为一个音色文件走克隆生成语音的接口。

### 6.2 功能

- 可以选择一轨自定义音色文件参与混合
- 混合后生成新的音色文件

## 7. 提示词生成语音

不再走纯"提示词生成语音"功能，而是生成后作为一个音色文件走克隆生成语音的接口。
