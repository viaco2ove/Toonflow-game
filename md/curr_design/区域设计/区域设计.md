# 背景 
当前游戏是文本对话的ai 游戏
所以一开始没有做地图啊，区域啊这样的模块。
我们也没有做对角色进行闭言的操作设计。

# 地图设计
```json
{
  "区域": [{
    "区域名称":"阳间",
    "描述": "这是阳间",
    "子区域": [{
    "区域名称":"诡异学校",
    "描述": "诡异学校",
    "子区域": []}
    ]
  },
  {
    "区域名称":"阴间",
    "描述": "这是阴间"
  }
  ],
  "激活说话的区域": [
    "阳间"
  ]
}
```
默认激活区域是阳间。
- 那么谁来我维护这个地图数据呢？
“记忆管理器”和“意图分析师”这两个agent 负责维护这个地图数据。
- 什么时候生成？
进入ai故事时。和需要改动时。
地图数据要发送给谁？
“记忆管理器”和“情编排师”，“任务剧情编排师”，“角色发言器”和“任务角色发言器”和“小游戏角色发言器”

- 激活说话的区域
不一定需要在“区域”这个字段里。

# 角色卡的字段增加，所在区域
默认角色都是在阳间。也就是都能说话

# 问题
- 增加ai 游戏复杂度
- 激活说话的区域的更新不及时导致游戏混乱
- 角色的“所在区域”更新不及时。
