## 2. 数据模型：`t_plugin`

```sql
CREATE TABLE t_plugin (
  id            INTEGER PRIMARY KEY,
  userId        INTEGER NOT NULL,           -- 用户隔离（每用户一套安装）
  pluginId      TEXT NOT NULL,              -- manifest.id
  name          TEXT,                       -- manifest.name.fallback
  version       TEXT,                       -- manifest.version
  author        TEXT,
  description   TEXT,
  dir           TEXT NOT NULL,              -- 插件文件目录名
  entry         TEXT,                       -- 前端入口（manifest.entry）
  backendEntry  TEXT,                       -- 后端入口（manifest.backendEntry，可空）
  manifestJson  TEXT NOT NULL,              -- 完整 manifest 快照
  enabled       INTEGER DEFAULT 1,          -- 1 启用 / 0 禁用
  status        TEXT DEFAULT 'installed',   -- installed | disabled | error
  installedAt   BIGINT,                     -- 安装时间 ms
  updatedAt     BIGINT                      -- 更新时间 ms
);
CREATE UNIQUE INDEX idx_plugin_user_plugin ON t_plugin (userId, pluginId);
```

迁移文件：`src/migrations/20260921_000001_add_plugin_table.js`，与现有 Knex 迁移体系一致，幂等。

## 3. API 接口

| 方法 | 路径 | 鉴权 | 用途 |
|------|------|------|------|
| POST | `/plugin/list` | JWT | 列出当前用户已安装插件 |
| POST | `/plugin/install` | JWT | 安装/覆盖升级插件（base64 zip） |
| POST | `/plugin/uninstall` | JWT | 卸载插件 |
| POST | `/plugin/setEnabled` | JWT | 启用/禁用插件 |
| GET | `/plugin/getAsset` | JWT（query token） | 读取插件内静态资源 |

所有 POST 接口统一返回 `{ code: 200, data, message }` 信封；失败返回 4xx 并附 `message`。

### 3.1 `/plugin/install` 请求

```json
{
  "fileName": "toonflow-field-survival-1.0.0.tpg",
  "base64Data": "UEsDBAoAAAAAAAAAIQ..."
}
```

返回：

```json
{
  "code": 200,
  "data": {

    "upgraded": false
  },
  "message": "成功"
}
```

### 3.3 `/plugin/getAsset`

```
GET /plugin/getAsset?pluginId=...&path=ui/game.html&token=<jwt>
```

- 浏览器 `<script src>` / `<iframe src>` / `<img src>` 可直接引用
- JWT 既支持 `Authorization` 头也支持 `?token=` query（全局 JWT 中间件已经支持）
- 文件 MIME 自动识别；JS/CSS/HTML 带 utf-8 charset
- **路径穿越防护**：`../`、`..\`、绝对路径全部返回 404，路径必须落在 `<数据根>/Toonflow-game/plugins/<userId>/<pluginId>/` 内

## 4. 插件文件存储

```
<数据根>/Toonflow-game/plugins/
└── <userId>/
    └── <pluginId>/
        ├── manifest.json
        ├── entry.js
        ├── entry.py
        ├── ui/
        │   └── game.html
        └── locales/
            └── zh-CN.json
```

- 用户隔离：每用户独立目录
- 卸载时按"改名→删除"避免 Windows 文件锁（删除失败不阻塞卸载记录）
- 安装时先解压到 `.tmp/<timestamp>-<uuid>/`，定位 manifest 所在目录，再原子重命名到目标位置

## 5. 资源隔离兼容

`/plugin/*` 路径未列入 `PROJECT_SCOPED_PREFIXES`，所以：
- 全局 JWT 中间件正常生效（`/plugin/*` 不在 `/other/*` 白名单内）
- `enforceResourceIsolation` 走默认分支返回 401（如未登录）；已登录的合法用户不携带 projectId 时也走 `return next()` 默认放行

**不需要改 `resourceIsolation.ts`**。
