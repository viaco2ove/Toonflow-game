# 统计与日志

## 1. 概述

统计与日志系统用于记录 AI Token 消耗、追踪系统运行状态、帮助调试和优化性能。

## 2. 当前实现状态

- 后端已落 `t_aiTokenUsageLog`
- 统一从 `u.ai.text.invoke` 记录 token 明细
- 已提供 `/setting/getAiTokenUsageLog` 与 `/setting/getAiTokenUsageStats`
- Web 设置页与安卓设置页的"其他"区域均已增加"token消耗"入口
- 已补金额字段：`inputPricePer1M / outputPricePer1M / cacheReadPricePer1M / amount / currency`
- 模型配置管理支持录入文本模型单价，金额按"每 100 万 token 单价"实时换算
- 明细与统计面板均已展示金额

## 3. Token 消耗面板

### 3.1 入口

在设置的其他，增加一个"token消耗"按钮，点击打开 Token 消耗面板。

### 3.2 日志明细

**查询条件**：
- 时间（开始、结束）
- 类型

**列表字段**：
| 字段 | 说明 |
|------|------|
| 时间 | 记录时间 |
| 业务类型 | 编排师/记忆管理/角色发言等 |
| 模型 | 使用的 AI 模型 |
| 渠道 | volcengine/openai 等 |
| token 量 | 输入/输出 token 数量 |
| 金额 | 实际消费金额 |
| 备注 | 额外说明 |

### 3.3 统计面板

**查询条件**：
- 时间（开始、结束）
- 类型
- 统计类型（日/时/月）

**列表字段**：同日志明细

## 4. 数据表结构

### 4.1 Token 使用日志表 (t_aiTokenUsageLog)

```sql
CREATE TABLE t_aiTokenUsageLog (
  id INTEGER PRIMARY KEY,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  business_type VARCHAR(50),      -- 业务类型：orchestration/memory/speaker/chapter 等
  model VARCHAR(100),            -- 模型名称
  manufacturer VARCHAR(50),       -- 渠道：volcengine/openai/deepseek 等
  input_tokens INTEGER,           -- 输入 token 数
  output_tokens INTEGER,          -- 输出 token 数
  cache_read_tokens INTEGER,      -- 缓存读取 token 数
  input_price_per_1m DECIMAL,    -- 输入单价（每百万）
  output_price_per_1m DECIMAL,   -- 输出单价（每百万）
  cache_read_price_per_1m DECIMAL, -- 缓存读取单价（每百万）
  amount DECIMAL,                -- 实际金额
  currency VARCHAR(10),           -- 货币单位
  session_id VARCHAR(100),        -- 会话 ID
  chapter_id VARCHAR(100),        -- 章节 ID
  remarks TEXT                    -- 备注
);
```

## 5. 统计分类

### 5.1 业务类型

| 类型 | 说明 |
|------|------|
| `orchestration` | 编排师 |
| `memory` | 记忆管理 |
| `speaker` | 角色发言 |
| `chapter` | 章节判定 |
| `mini_game` | 小游戏控制 |
| `safety` | 安全审查 |
| `image` | AI 生图 |
| `voice` | 语音生成 |

### 5.2 统计维度

- **按时间**：日/时/月
- **按业务类型**：分类统计
- **按模型**：不同模型消耗对比
- **按渠道**：不同 AI 厂商消耗对比

## 6. 关键指标

| 指标 | 说明 |
|------|------|
| 总 token 消耗 | 输入 + 输出 + 缓存 |
| 总金额 | 实际消费 |
| 平均每轮消耗 | 总消耗 / 会话轮数 |
| 模型使用分布 | 各模型使用占比 |
| 业务类型分布 | 各业务类型消耗占比 |

## 7. 日志标签

| 标签 | 说明 |
|------|------|
| `chapter_progress` | 章节进度变化 |
| `trigger_hit` | 触发器命中 |
| `event_complete` | 事件完成 |
| `orchestration` | 编排结果 |
| `memory_refresh` | 记忆刷新 |
| `mini_game` | 小游戏状态 |
| `state_delta` | 状态变更 |

## 8. 调试日志

### 8.1 Web/Android Debug Tags

- 战斗小游戏旁白硬编码需删除
- 全链路日志需添加 debug tags
- 前端/后端状态同步日志

### 8.2 常见问题排查

**问题 1：章节不结束**
- 检查 `endingRules` 是否正确配置
- 检查 `completionCondition` 是否满足
- 查看 `completedEvents` 列表

**问题 2：章节提前结束**
- 检查 `evaluateCondition` 函数逻辑
- 检查条件表达式是否正确

**问题 3：动态事件不生成**
- 检查自由章节配置
- 检查 AI 编排师返回
