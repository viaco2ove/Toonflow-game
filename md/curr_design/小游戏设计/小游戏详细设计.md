# 小游戏详细设计

## 1. 狼人杀

### 1.1 定位

适合社交局、营火局、宿舍局、聚会剧情。重点是关系变化、观察角色性格、制造支线冲突。

### 1.2 核心参数

**public_state**：
- `day_count`
- `alive_list`
- `eliminated_list`
- `public_vote_history`
- `discussion_order`
- `last_night_result`

**hidden_state**：
- `role_map`
- `wolf_target`
- `seer_checks`
- `witch_save_used`
- `witch_poison_used`
- `npc_suspicion_matrix`
- `npc_personality_weight`

### 1.3 流程

```
setup → night_wolf → night_seer → night_witch → 
day_announce → day_discussion → day_vote → settling
```

### 1.4 用户可选动作

**狼人**：`击杀X`、`空刀`、`查看局势`
**预言家**：`查验X`、`跳过`
**女巫**：`救X`、`毒X`、`双跳过`
**白天**：`发言`、`投票X`、`弃票`、`查看记录`

### 1.5 胜负条件

- 所有狼人出局 → 村民阵营胜
- 存活狼人数量 >= 其他存活人数 → 狼人阵营胜
- 用户提前出局可进入旁观模式

## 2. 钓鱼

### 2.1 定位

轻度资源玩法，适合放松、采集、支线素材获取，也可以挂接烹饪、交易和炼药材料。

### 2.2 场景模板

| 场景 | 遇鱼率 | 稀有率 | 推荐鱼种 |
|------|--------|--------|---------|
| 小河 | 55 | 5 | 鲫鱼、河虾 |
| 湖泊 | 45 | 12 | 青鱼、银鲤 |
| 深潭 | 35 | 20 | 灵鱼、古鳞鱼 |

### 2.3 核心参数

**public_state**：
- `site_name`, `bait_name`, `stamina`, `focus`, `line_tension`, `fish_distance`, `hook_state`

**hidden_state**：
- `target_fish_id`, `fish_stamina`, `fish_power`, `fish_escape_rate`, `encounter_roll`

### 2.4 基础公式

咬钩概率：
```
hook_chance = 场景遇鱼率 + 鱼饵加成 + 时间段加成 + 装备加成 + 天气加成 - 噪音惩罚
```

限制在 `10~95`。

### 2.5 中鱼后阈值

- `line_tension >= 100` → 断线失败
- `fish_distance > 120` → 脱钩失败
- `fish_distance <= 0 且 fish_stamina <= 0` → 成功上岸

### 2.6 流程

```
prepare → cast → waiting → hook_fight → landing → settling
```

### 2.7 用户动作

| 动作 | 效果 |
|------|------|
| `抛竿` | 开始钓鱼 |
| `提竿` | 咬钩判定 |
| `收线` | distance -20, tension +20, fish_stamina -10 |
| `放线` | distance +10, tension -25 |
| `稳杆` | distance -5, tension -15, fish_stamina -5 |
| `侧拉` | distance -15, tension +10, fish_stamina -15 |
| `强拉` | distance -30, tension +35, fish_stamina -25 |
| `换饵` | 更换鱼饵 |
| `收杆结束` | 结束钓鱼 |

## 3. 修炼

### 3.1 定位

角色成长型玩法。把修炼过程拆成可判定的资源管理与突破过程。

### 3.2 核心参数

**public_state**：
- `qi`, `insight`, `stability`, `fatigue`, `breakthrough_progress`, `current_method`

**hidden_state**：
- `deviation_risk`, `bonus_event_roll`, `environment_bonus`, `bottleneck_level`

参数范围：
- `qi`：`0~100`
- `insight`：`0~100`
- `stability`：`0~100`
- `fatigue`：`0~100`
- `deviation_risk`：`0~100`
- `breakthrough_progress`：`0~100`

### 3.3 流程

```
choose_method → gather_qi → circulate → breakthrough → settling
```

### 3.4 用户动作

| 动作 | 效果 |
|------|------|
| `吐纳` | qi +18, fatigue +8 |
| `观想` | insight +15, fatigue +6 |
| `稳息` | stability +18, deviation_risk -12 |
| `服丹` | qi +25, stability -5, 每局最多一次 |
| `冲关` | 满足条件则 progress +25~45, 否则触发反噬 |
| `收功` | 安全结束，按当前进度折算经验 |

### 3.5 风控规则

- `fatigue > 70` 时，每轮 `deviation_risk +15`
- `stability < 30` 时，`冲关` 失败概率大增
- `deviation_risk >= 100` 立即中断本局，走火入魔失败

### 3.6 胜负条件

- `breakthrough_progress >= 100` 且 `deviation_risk < 60` → 突破成功
- 主动 `收功` → 按当前积累发放普通收益
- 风险爆表 → 失败，写入负面状态或短期 debuff

## 4. 研发技能

### 4.1 定位

用于"自创招式"、"研发装置"、"写法术模型"、"技能迭代"。

### 4.2 核心参数

**public_state**：
- `target_skill_name`, `complexity`, `theory_progress`, `prototype_progress`, `stability_score`, `turn_left`

**hidden_state**：
- `inspiration_roll`, `failure_threshold`, `synergy_bonus`, `mentor_bonus`

复杂度建议：
- `1`：小技能修订
- `2`：基础技能开发
- `3`：进阶技能开发
- `4`：稀有技能开发
- `5`：特殊传承技能开发

### 4.3 流程

```
select_blueprint → theory_research → prototype_test → debug_refine → finalize → settling
```

### 4.4 用户动作

| 动作 | 效果 |
|------|------|
| `理论推演` | theory +20 |
| `样本拆解` | theory +15, 消耗材料 1 |
| `原型实验` | prototype +25, stability -10 |
| `故障排查` | stability +20 |
| `请教同伴` | theory +10 或 inspiration +15 |
| `强行迭代` | prototype +35, stability -20 |
| `定稿封存` | 达标后进入结算 |

### 4.5 完成阈值

- `theory_progress >= 60 + complexity * 10`
- `prototype_progress >= 50 + complexity * 10`
- `stability_score >= 40`

### 4.6 结算回写

- 成功 → `skill_unlocks`, `skill_book`, `event_pool.done`
- 半成功 → `skill_fragment`
- 失败 → 只保留研究笔记

## 5. 炼药

### 5.1 定位

资源转化型玩法，适合战斗前准备、治疗、强化、宗门生活类剧情。

### 5.2 核心参数

**public_state**：
- `recipe_name`, `round_limit`, `heat`, `purity`, `fusion`, `toxicity`, `stability`

**hidden_state**：
- `target_heat_min`, `target_heat_max`, `required_order`, `ingredient_match_score`, `rare_mutation_roll`

数值范围：
- `heat`：`0~100`
- `purity`：`0~100`
- `fusion`：`0~100`
- `toxicity`：`0~100`
- `stability`：`0~100`

### 5.3 流程

```
select_recipe → preheat → main_refine → stabilize → condense → appraise → settling
```

### 5.4 用户动作

| 动作 | 效果 |
|------|------|
| `升火` | heat +15 |
| `降火` | heat -15 |
| `投药` | 顺序正确则 fusion +20, 错误则 toxicity +15 |
| `搅拌` | fusion +10, stability +5 |
| `稳炉` | stability +15, heat -5 |
| `提纯` | purity +15, fusion -5 |
| `凝丹` | 满足阈值时进入结算 |

### 5.5 风险规则

- 热度超出目标带 `20` 以上时，`stability -10`, `toxicity +10`
- `toxicity >= 100` → 判定炸炉失败
- `stability <= 0` → 判定药液报废

### 5.6 品质公式

```
quality_score = purity * 0.35 + fusion * 0.35 + stability * 0.2 - toxicity * 0.2 + 配方匹配加分
```

## 6. 挖矿

### 6.1 定位

采集与探索型玩法，适合资源产出、危险探索和章节素材积累。

### 6.2 场景模板

| 场景 | 富矿度 | 风险值 | 稀有率 |
|------|--------|--------|--------|
| 露天矿 | 60 | 20 | 5 |
| 洞窟矿 | 80 | 40 | 12 |
| 灵脉矿 | 100 | 60 | 20 |

### 6.3 核心参数

**public_state**：
- `mine_name`, `vein_hp`, `stability`, `danger`, `player_stamina`, `tool_durability`, `bag_load`

**hidden_state**：
- `ore_table`, `rare_drop_roll`, `weakness_point`, `collapse_threshold`

### 6.4 流程

```
survey → choose_vein → excavate → risk_check → haul → settling
```

### 6.5 用户动作

| 动作 | 效果 |
|------|------|
| `勘探` | 发现弱点后，下次开采效率 +20% |
| `开采` | vein_hp - 基础采矿力, stamina -15, danger +10 |
| `精挖` | 小幅削减 vein_hp, 稀有率 +15%, stamina -20 |
| `支护` | stability +20, danger -15 |
| `清障` | bag_load -10 或提升下一轮效率 |
| `休息` | stamina +20 |
| `撤离` | 保留当前收益并结算 |

### 6.6 风险规则

- `danger >= 70` 时，每轮都要做坍塌判定
- `stability <= 20` 且继续开采时，坍塌概率大增
- 坍塌后优先扣体力、耐久和部分矿石

## 7. 升级装备

### 7.1 定位

短回合锻造，让用户通过操作降低失败风险。

### 7.2 核心参数

**public_state**：
- `equip_id`, `equip_name`, `equip_type`, `current_level`, `target_level`, `forge_heat`, `forge_progress`, `stability`, `spirit_sync`

**hidden_state**：
- `optimal_heat_min`, `optimal_heat_max`, `failure_risk`, `bonus_affix_roll`

推荐热区：
- 武器：`60~80`
- 护甲：`50~70`
- 饰品：`40~60`

### 7.3 流程

```
select_equip → heat_up → forge → temper → infuse → finalize → settling
```

### 7.4 用户动作

| 动作 | 效果 |
|------|------|
| `加热` | heat +20, progress +5 |
| `锻打` | 热区正确时 progress +20, 否则 stability -10 |
| `校正` | stability +15, heat -10 |
| `淬火` | spirit_sync +10~25, 错误淬火则 stability -15 |
| `注灵` | spirit_sync +20, failure_risk +10 |
| `收工定型` | 满足阈值后进入结算 |

### 7.5 成功阈值

- `forge_progress >= 80`
- `stability >= 50`
- `spirit_sync >= 40`

### 7.6 结果分级

- **完美成功**：`+1` 强化等级，并追加一个小词条或额外耐久
- **普通成功**：`+1` 强化等级
- **半成功**：等级不变，但提升耐久或积累保底值
- **失败**：扣材料与耐久

MVP 不建议默认掉级。

## 8. 战斗

### 8.1 定位

即时战斗玩法，与野怪或角色进行回合制战斗。

### 8.2 触发方式

```
#战斗 萧家子弟
#战斗 野怪
#战斗 暴风狼
```

### 8.3 流程

```
#战斗 角色名
    ↓
创建敌人对象和状态
    ↓
旁白：询问是否准备好战斗
    ↓
用户：施展技能攻击
    ↓
旁白：播报伤害结果
    ↓
敌人：反击
    ↓
... 循环 ...
    ↓
一方血量归零 → 结算
```

### 8.4 伤害公式

```
攻击力 = 等级 + 技能等级 + 加成
伤害 = 攻击力 - 防御
```

### 8.5 战斗播报示例

```
旁白：装备好与萧家子弟(lv1)进行战斗了吗？
用户：施展灭魔步攻击。
旁白：你施展了灭魔步对对方造成了30点攻击，对方剩余血量70。
某男子:(扮演萧家子弟)，烈焰掌
旁白：萧家子弟对你造成22点攻击，剩余血量78；建议使用补血丹lv1。
用户：吃下补血丹，灭魔尺和灭魔步
旁白：你施展了灭魔步对对方造成了42点攻击，对方剩余血量28；你的血量为99，消耗了一颗补血丹lv1。
某男子:(扮演萧家子弟)，看我的，天龙拳。
...
旁白：萧家子弟血量为0，恭喜你战胜了萧家子弟(lv1)，奖励金钱10，一颗补血丹lv1。
```

### 8.6 结算奖励

- 金钱
- 经验
- 掉落物品
