# 角色参数卡详细设计

## 1. 设计原则

角色卡分成两层：

### 1.1 用户创建层（前台）

用户在创建角色时，只填写少量直观字段：
- 头像
- 角色名
- 角色设定
- 角色音色
- 台词示例

### 1.2 系统参数层（后台）

系统根据"角色设定"等内容，自动生成一张结构化参数卡 JSON。

## 2. 字段结构

### 2.1 基础信息 `basic`

```json
{
  "id": "",
  "name": "",
  "aliases": [],
  "gender": "",
  "age": null,
  "race": "",
  "occupation": "",
  "camp": "",
  "tags": []
}
```

### 2.2 原始设定 `source`

```json
{
  "raw_setting": "",
  "raw_voice_style": "",
  "raw_sample_lines": []
}
```

### 2.3 世界观信息 `world`

```json
{
  "era": "",
  "region": "",
  "faction": "",
  "background_summary": ""
}
```

### 2.4 外观信息 `appearance`

```json
{
  "body_type": "",
  "height": "",
  "hair": "",
  "eyes": "",
  "clothing_style": "",
  "distinctive_features": []
}
```

### 2.5 声音信息 `voice`

```json
{
  "tone": "",
  "speed": "",
  "volume": "",
  "style_keywords": []
}
```

### 2.6 性格信息 `personality`

```json
{
  "core_traits": [],
  "temper": "",
  "values": [],
  "likes": [],
  "dislikes": [],
  "fears": [],
  "weaknesses": []
}
```

### 2.7 行为模式 `behavior`

```json
{
  "speaking_style": "",
  "habit_actions": [],
  "decision_style": "",
  "social_attitude": ""
}
```

### 2.8 动机目标 `motivation`

```json
{
  "short_term_goal": "",
  "long_term_goal": "",
  "core_desire": "",
  "taboos": []
}
```

### 2.9 关系信息 `relationships`

```json
{
  "default_attitude_to_player": "",
  "important_people": [
    {
      "name": "",
      "relation": "",
      "attitude": "",
      "notes": ""
    }
  ]
}
```

### 2.10 能力信息 `abilities`

```json
[
  {
    "name": "",
    "type": "combat|social|magic|passive|utility|special",
    "description": "",
    "cooldown": "",
    "limit": ""
  }
]
```

### 2.11 物品装备 `inventory`

```json
{
  "items": [],
  "equipment": [],
  "resources": []
}
```

### 2.12 互动规则 `interaction_rules`

```json
{
  "can_romance": false,
  "can_betray": false,
  "can_join_team": true,
  "response_length_preference": "short|medium|long",
  "nsfw_level": "none|low|medium|high",
  "knowledge_boundary": "",
  "secret_level": "low|medium|high"
}
```

### 2.13 演出信息 `performance`

```json
{
  "catchphrases": [],
  "sample_lines": [],
  "emotion_triggers": [],
  "first_impression": "",
  "revealed_impression": ""
}
```

### 2.14 扩展字段 `extension`

```json
{
  "custom_traits": [],
  "extra_notes": ""
}
```

## 3. 完整 JSON 模板

```json
  "inventory": {},
  "interaction_rules": {},

```

| 暴躁 |
| 温和 |
| 阴郁 |

| 克制 |

|----|

| 疏离型 |

## 5. 前台输入与后台生成映射

### 5.1 前台输入

```json
{
  "avatar": "",
  "name": "",
  "role_setting": "",
  "voice_style": "",
  "sample_lines": []
}
```

### 5.2 后台生成映射

| 前台字段 | 后台字段 |
|---------|---------|
| `name` | `basic.name` |
| `role_setting` | 拆解进 `world / personality / behavior / motivation / relationships / abilities` |
| `voice_style` | `source.raw_voice_style` + `voice` |
| `sample_lines` | `source.raw_sample_lines` + `performance.sample_lines` |

## 7. 必须固定的字段

以下字段必须放进固定字段，不得放入 `extra_notes`：

| 类别 | 字段 |
|------|------|
| 基础 | `basic` |
| 世界观 | `world` |
| 外观 | `appearance` |
| 声音 | `voice` |
| 性格 | `personality` |
| 行为 | `behavior` |
| 动机 | `motivation` |
| 关系 | `relationships` |
| 能力 | `abilities` |
| 物品 | `inventory` |
| 规则 | `interaction_rules` |
| 演出 | `performance` |
