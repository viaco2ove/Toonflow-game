# 游戏参数详细设计

## 1. 概念区分

| 概念 | 核心作用 | 主要用途 |
|------|---------|---------|
| **AI 故事** | 描述故事内容和结构的静态数据 | 存放剧情、背景、角色信息、世界观设定等 |
| **AI 故事游玩** | 交互式故事体验的动态数据 | 包含用户选择、进度状态、角色状态、变量变化等 |

### 核心区别

| 维度 | AI 故事 | AI 故事游玩 |
|------|---------|------------|
| 数据类型 | 静态 | 动态 |
| 更新频率 | 低（发布时固定） | 高（游玩时实时） |
| 用途 | 设计与生成故事 | 支持用户交互和剧情推进 |
| 字段 | 标题、简介、角色列表、章节结构、世界观 | 用户选择、当前章节、角色状态（血量、技能冷却）、变量（金钱、道具）、事件触发状态 |
| 一对多 | 一份故事可被多个用户游玩 | 每位用户/每个游玩会话生成一条记录 |

## 2. 推荐表结构

### 2.1 故事运行表 (game_run)

```json
{
  "id": 1,
  "story_id": 1,
  "player_id": 1,
  "status": "running|paused|ended",
  "current_chapter_id": "ch_001",
  "current_scene_id": "scene_003",
  "turn": 0,
  "created_at": "",
  "updated_at": ""
}
```

### 2.2 快照表 (game_run_snapshot)

```json
{
  "id": 1,
  "game_run_id": 1,
  "turn": 12,
  "snapshot_json": {},
  "created_at": ""
}
```

**说明**：每 `N` 轮 + 关键事件强制落快照

### 2.3 事件表 (game_run_event)

```json
{
  "id": 1,
  "game_run_id": 1,
  "event_type": "trigger|complete|fail",
  "event_key": "quest_001",
  "payload_json": {},
  "result": "",
  "turn": 5,
  "created_at": ""
}
```

### 2.4 记忆表 (game_run_memory)

```json
{
  "id": 1,
  "game_run_id": 1,
  "memory_level": "short|mid|long",
  "topic": "relationship",
  "content": "用户与萧炎建立了友好关系",
  "importance": 3,
  "ttl_turn": 20,
  "source_turn": 12,
  "status": "active|expired",
  "created_at": "",
  "updated_at": ""
}
```

### 2.5 记忆摘要表 (game_run_memory_summary)

```json
{
  "id": 1,
  "game_run_id": 1,
  "summary_type": "mid_term",
  "summary_text": "用户已完成新手任务，与纳兰嫣然和萧炎建立了初步关系",
  "based_on_turn_start": 1,
  "based_on_turn_end": 20,
  "created_at": ""
}
```

## 3. 游玩动态信息

### 3.1 游玩动态信息类型

| 类型 | 说明 |
|------|------|
| 故事动态背景 | 来源于故事本身，每个用户游玩时独立且相对动态 |
| 游玩进度 | 用户游玩到哪个章节 |
| 事件池 | 已完成/未完成的人物和触发的剧情 |
| 当前位置 | 用户在哪个场地、正在做什么 |

### 3.2 动态信息说明

**故事动态背景精炼总结**：
- 来源于故事本身
- 每个用户游玩时独立
- 相对动态变化

**用户参数 JSON 转精炼文本**：
- 不要发送 JSON 格式
- 转换为简洁文本

**章节内容精炼文本**：
- 当前章节内容提取为精炼文本
- 用于上下文装载

**角色信息精炼文本**：
- 角色参数卡转换为精炼文本
- 减少 token 消耗

## 4. 数据初始化流程

持久化绑定到当前对话：

```
1. 加载故事动态背景精炼总结（加载，缺少才生成）
2. 加载角色动态参数卡（加载，缺少才生成）
3. 加载故事动态参数（加载，缺少才生成）
4. 加载角色精炼文字（加载，缺少才生成）
```

**注意**：故事发布时（调试时也）先预先生成一份静态的，用于第一次进入快速生成动态数据。

## 5. 编排阶段触发记忆处理

触发条件：
- 编排师触发
- 线程 30 秒扫到有新台词

处理内容：
- 故事动态背景精炼总结 + 20条台词 + agent 提示词 → 新的故事动态背景精炼总结
- 新的故事动态背景精炼总结 + 20条台词 + agent 提示词 + 角色精炼文字 → 新的角色参数卡 + 新的角色精炼文字
- 调整故事动态参数

## 6. 状态流转图

```
┌─────────────────────────────────────────────────────────────┐
│                        game_run                              │
├─────────────────────────────────────────────────────────────┤
│  静态内容层                                                 │
│  ├── 故事 (story)                                          │
│  ├── 章节 (chapter)                                         │
│  ├── 角色 (role)                                            │
│  └── 世界观 (world)                                         │
├─────────────────────────────────────────────────────────────┤
│  动态运行层                                                 │
│  ├── 当前章节 (current_chapter)                             │
│  ├── 当前场景 (current_scene)                               │
│  ├── 用户位置 (location)                                    │
│  └── 关系值 (relationship)                                  │
├─────────────────────────────────────────────────────────────┤
│  局部模式层                                                 │
│  └── 小游戏局内状态 (mini_game_session)                     │
├─────────────────────────────────────────────────────────────┤
│  记忆层                                                     │
│  ├── 短期记忆 (short_term) - 最近对话窗口                   │
│  ├── 中期记忆 (mid_term) - 关键事实摘要                     │
│  └── 长期记忆 (long_term) - 世界观设定                      │
└─────────────────────────────────────────────────────────────┘
```

## 7. 关系图

```
AI故事 (静态)
    │
    └── 角色表 (t_game_parameter)
            │
            └── parameterCardJson (静态参数卡)
                    │
                    ▼
            游戏运行时 (game_run)
                    │
                    ├── 快照 (snapshot)
                    ├── 事件 (event)
                    ├── 记忆 (memory)
                    │       ├── 短期
                    │       ├── 中期
                    │       └── 长期
                    │
                    └── 游玩中的角色参数 (game_run_parameter)
                            │
                            └── 动态参数值（每个用户独立）
```

## 8. 游玩参数表关系

| 表名 | 关系 | 说明 |
|------|------|------|
| `t_game_world` | 1-N | 游戏世界 |
| `t_game_chapter` | N-1 | 游戏章节 |
| `t_game_parameter` | 1-N | 角色参数卡（静态） |
| `t_game_session` | N-1 | 游戏会话 |
| `t_game_message` | N-1 | 会话消息 |
| `t_game_snapshot` | N-1 | 状态快照 |
| `t_game_run_parameter` | N-1 | 游玩中的角色参数（动态） |
