# 自由章节设计

## 1. 概述

自由章节是 AI 故事游戏中没有固定结束条件的章节类型，由 AI 动态生成事件，用户提供方向。

## 2. 自由章节特点

1. **零个或有限的静态事件数据**
2. **没有结束条件**
3. **当前章节事件可能为空**
4. **AI 不断产生新的事件加入到动态事件**
5. **永远不结束，除非用户主动退出或切换章节**

## 3. 与非自由章节的区别

| 特性 | 非自由章节 | 自由章节 |
|------|-----------|---------|
| 结束条件 | 有 | 无 |
| 静态事件 | 有 | 零个或有限 |
| 动态事件 | AI 可补充 | AI 不断生成 |
| 章节状态 | 未结束/成功/失败 | 持续进行 |
| 退出方式 | 达到条件自动结束 | 用户主动退出 |

## 4. 动态事件状态管理

### 4.1 初始化

```typescript
// 自由章节动态事件状态初始化
ensureFreeChapterDynamicEventState(sessionId, chapterId)
```

### 4.2 事件生成

当用完有限的静态事件数据后：
1. 编排师判断需要新事件
2. AI 生成新事件内容
3. 创建新的动态事件数据
4. 持久化绑定到会话

### 4.3 事件状态

```typescript
interface RuntimeDynamicEventState {
  eventId: string;
  phaseId: string;
  flowType: "fixed" | "dynamic";
  runtimeFacts: Record<string, any>;
  memorySummary: string;
  status: "idle" | "active" | "waiting_input" | "completed";
}
```

## 5. 任务推荐系统

### 5.1 触发方式

用户输入"给我推荐个任务"时，从不同类别中一次推荐5个任务。

### 5.2 任务分类

**生存类**：寻找安全据点、收集基础资源、修复临时庇护所等

**成长类**：提升能量掌控、学习基础战斗方式、强化肉身承受力等

**探索类**：调查遗迹、搜索隐藏通路、探查能量异常点等

**交互类**：接触西游孙悟空、接触龙珠悟空、追踪徐阳等

**对抗类**：击退裂隙异兽、抵挡混沌侵蚀体、挑战流窜强敌等

**机缘类**：抢夺掉落宝物、搜寻古老传承、获取神木碎片等

**阵营类**：选择临时同盟、加入某方行动、建立个人势力雏形等

**隐藏类**：未公开任务、特殊触发任务、连锁命运任务等

### 5.3 任务特点

- 同一类型任务，不一定每次都相同
- 同一任务可能在不同时间再次出现
- 难度、目标、涉及角色会发生变化

## 6. 编排流程

```
编排师发送：
  - 对话内容（砍为10个台词）
  - 当前事件内容（可能为空）
  - 事件序号
  - 各个角色简洁的文字化动态参数卡

编排大模型返回：
  - 下个角色
  - 角色动机
  - 事件内容是否需要调整
  - 是否需要触发记忆管理

判断：
  - 没有达到结束条件 → 继续编排
  - 事件内容为空 → 返回新的事件内容，创建新的动态事件数据
```

## 7. 与小游戏的关系

自由章节中可触发小游戏：
- 主动触发：用户输入 `#狼人杀` `#钓鱼` `#修炼` 等
- 被动触发：剧情中自然触发（如烧烤局狼人杀）

小游戏结束后返回自由章节继续。

## 8. 与其他模块的关系

- **ChapterProgressEngine**：处理自由章节动态事件
- **NarrativeOrchestrator**：AI 生成事件内容
- **MiniGameController**：小游戏集成
- **SessionService**：事件状态存储
