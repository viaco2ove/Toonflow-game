# 游玩时的语音克隆生成

## 1. 概述

语音克隆（Voice Clone）是 AI 故事游戏的重要组成部分，为每个角色提供独特的语音，提升沉浸感。

## 2. 语音生成流程

### 2.1 流程图

```
角色发言生成
    ↓
文本内容确定
    ↓
异步语音请求 (voice async)
    ↓
语音克隆处理
    ↓
返回音频 URL
```

### 2.2 关键原则

**语音不能阻塞正文首屏**

正文必须先落，语音统一异步处理。

## 3. 语音模式

### 3.1 Immediate 模式

- 当前消息刚落库就异步请求语音
- 用于关键角色的重要台词

### 3.2 Deferred 模式

- 用户停留时再请求
- 用于普通 NPC 或过场台词

### 3.3 Skip 模式

- 不生成语音
- 用于纯旁白或环境描述

## 4. 音色设计

### 4.1 角色音色特点

每个角色有独特的音色特点：

```json
{
  "name": "萧炎",
  "voice": {
    "type": "克隆",
    "pitch": "低沉",
    "tempo": "中等",
    "emotion": "压抑、克制"
  }
}
```

### 4.2 旁白音色

旁白优先走标准音色：
- 不需要每轮都跑复杂克隆链
- 进一步减少等待时间

## 5. 语音网关

voiceGateway.ts 是语音服务网关：

```typescript
interface VoiceRequest {
  text: string;
  roleId: string;
  voiceConfig?: {
    pitch?: number;
    tempo?: number;
    emotion?: string;
  };
  mode: "immediate" | "deferred" | "skip";
}

interface VoiceResponse {
  audioUrl: string;
  duration?: number;
}
```

## 6. 支持的语音服务商

- 阿里云语音合成
- 火山引擎语音
- OpenAI TTS
- 自定义语音克隆 API

## 7. 游玩时语音生成

### 7.1 语音克隆预设

每个角色可配置语音克隆预设：
- 参考音频 URL
- 音色参数
- 情感倾向

### 7.2 动态语音生成

根据发言时的情感和语气，动态调整语音参数：
- 愤怒：音调提高，语速加快
- 悲伤：音调降低，语速减慢
- 兴奋：音调提高，语速加快，音量增加

## 8. 性能优化

### 8.1 缓存策略

- 相同文本的语音可缓存
- 常用角色的音色参数缓存

### 8.2 异步处理

- 语音生成不阻塞主流程
- 后台队列处理语音请求

### 8.3 降级策略

- 语音服务不可用时降级为静默模式
- 显示文字但不播放语音

## 9. 与其他模块的关系

- **NarrativeOrchestrator**：编排时决定语音模式
- **SpeakerRouteEngine**：发言路由决定音色选择
- **SessionService**：协调语音生成时机
