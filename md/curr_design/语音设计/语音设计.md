# 语音设计

## 1. 概述

语音设计涵盖 Web 端和 Android 端的语音交互差异、语音输入输出模式、以及语音在故事游玩中的集成。

## 2. Web 端与 Android 端差异

### 2.1 核心交互逻辑

| 设计环节 | 移动端（原设计） | Web 端（优化后） |
|----------|-----------------|-----------------|
| **触发方式** | 长按麦克风按钮 | 点击麦克风按钮（单次点击） |
| **录音状态** | 按住=录音，松开=发送 | 点击=开始录音，再次点击=结束录音 |
| **取消方式** | 上滑取消 | 提供「取消」按钮，或点击空白处取消 |
| **发送逻辑** | 松开自动发送 | 识别完成后，自动「发送」 |

### 2.2 Android 设计

- 按住进行录音
- 松开发送
- 上滑取消

### 2.3 Web 设计

Web 端鼠标没有「长按 + 滑动」的操作习惯，必须用「点击触发、点击结束」的无状态操作，降低学习成本。

## 3. 游玩时的语音克隆生成

### 3.1 语音生成流程

```
角色发言生成
    ↓
文本内容确定
    ↓
异步语音请求 (voice async)
    ↓
语音克隆处理
    ↓
返回音频 URL
```

### 3.2 关键原则

**语音不能阻塞正文首屏**

正文必须先落，语音统一异步处理。

### 3.3 语音模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| `immediate` | 当前消息刚落库就异步请求语音 | 关键角色的重要台词 |
| `deferred` | 用户停留时再请求 | 普通 NPC 或过场台词 |
| `skip` | 不生成语音 | 纯旁白或环境描述 |

## 4. 语音网关设计

### 4.1 接口定义

```typescript
interface VoiceRequest {
  text: string;
  roleId: string;
  voiceConfig?: {
    pitch?: number;
    tempo?: number;
    emotion?: string;
  };
  mode: "immediate" | "deferred" | "skip";
}

interface VoiceResponse {
  audioUrl: string;
  duration?: number;
}
```

### 4.2 支持的语音服务商

- 阿里云语音合成
- 火山引擎语音
- OpenAI TTS
- 自定义语音克隆 API

## 5. 角色音色配置

### 5.1 音色预设

每个角色可配置语音克隆预设：
- 参考音频 URL
- 音色参数
- 情感倾向

### 5.2 动态语音生成

根据发言时的情感和语气，动态调整语音参数：

| 情感 | 音调 | 语速 | 音量 |
|------|------|------|------|
| 愤怒 | 提高 | 加快 | 增加 |
| 悲伤 | 降低 | 减慢 | 减少 |
| 兴奋 | 提高 | 加快 | 增加 |
| 平静 | 中等 | 中等 | 中等 |

## 6. 边生成边播模式

### 6.1 流式 TTS + 边播

```
请求 TTS（流式）
    ↓
一边返回音频 chunk
    ↓
一边播放
```

**效果**：
- 首包：从 1-2秒 → 200-500ms
- 用户感觉：几乎秒开口

### 6.2 优化策略

#### 6.2.1 缓存音色 embedding

```
MP3 → embedding → 存缓存
之后直接用 embedding
```

#### 6.2.2 短句优先切分

按标点切分：
- `。！？` → 强切
- `，` → 不切
- 每段 20-40 字

#### 6.2.3 预热机制

提前调用一次空 TTS：
- GPU 预热
- 模型加载
- 首包减少 100-500ms

#### 6.2.4 音色连接复用

一次聊天会话长期保留音色连接，复用克隆音色 ID。

## 9. 语音识别

### 9.1 ASR 配置

在模型配置中独立设置：
- 语音识别（语音模型）

### 9.2 识别流程

```
用户语音输入
    ↓
ASR 转换为文字
    ↓
文本纠错
    ↓
发送消息
```

### 9.3 注意事项

- 语音输入自动转文字并纠错
- 切到文本模式后需手动切回语音模式
