# 实现计划：台词事件标记 & 非台词事件进度支持

## 问题背景

### 问题1：台词缺少事件/阶段标记
当前 `RuntimeMessageInput` 没有 `eventIndex` 和 `stageIndex` 字段，事件进度检测器无法知道每条台词属于哪个事件/阶段，导致无法正确判断事件进度。

### 问题2：非台词事件进度支持不足
章节定义中有类似规则：
```
### 遇见与交流
随机 遇见各种npc  @薰儿（萧薰儿|古薰儿） @纳兰嫣然 @海波东（冰皇） @美杜莎
聊天5轮对话后进入下个事件，用户发言5次.
```

系统无法正确处理"用户发言5次后进入下个事件"这类计数型条件。

## 实现方案

### 方案1：台词事件标记

#### 1.1 扩展消息结构
**文件**: `src/modules/game-runtime/engines/NarrativeOrchestrator.ts`

```typescript
export interface RuntimeMessageInput {
  messageId?: number | null;
  role?: string | null;
  roleType?: string | null;
  eventType?: string | null;
  content?: string | null;
  createTime?: number | null;
  // 新增：事件/阶段标记
  eventIndex?: number | null;
  stageIndex?: number | null;
  phaseId?: string | null;
  memoryDelta?: {...} | null;
}
```

#### 1.2 消息生成时写入标记
**文件**: `src/modules/game-runtime/engines/NarrativeOrchestrator.ts` (约5199行)

在生成 `on_orchestrated_reply` 消息时，从当前 `chapterProgress` 读取 eventIndex/stageIndex：

```typescript
const chapterProgress = readChapterProgressState(input.state);
const message: RuntimeMessageInput = {
  role: current.role,
  roleType: current.roleType,
  eventType: "on_orchestrated_reply",
  content: current.content,
  createTime: nowTs(),
  // 新增：事件/阶段标记
  eventIndex: chapterProgress.eventIndex,
  stageIndex: chapterProgress.stageIndex || 0,
  phaseId: chapterProgress.phaseId,
};
```

#### 1.3 事件进度检测输入包含标记
**文件**: `src/modules/game-runtime/services/EventProgressRuntimeService.ts`

修改 `buildEventProgressInputSnapshot` 函数，在 `recentDialogue` 中包含事件标记：

```typescript
const recentDialogue = Array.isArray(input.recentMessages)
  ? input.recentMessages
      .slice(-10)
      .map((item) => ({
        role: normalizeScalarText(item?.role) || "未知角色",
        role_type: normalizeScalarText(item?.roleType) || "",
        event_type: normalizeScalarText(item?.eventType) || "",
        content: shortText(item?.content, 160),
        // 新增：事件/阶段标记
        event_index: item?.eventIndex ?? null,
        stage_index: item?.stageIndex ?? null,
      }))
      .filter((item) => item.content)
  : [];
```

#### 1.4 更新事件进度检测器提示词
让AI能够根据台词的事件标记判断进度。

### 方案2：非台词事件进度支持

#### 2.1 解析用户发言次数规则
**文件**: `src/lib/gameEngine.ts`

在 `parsePhaseDirectiveLines` 中识别 "用户发言N次" 规则：

```typescript
// 匹配: "用户发言5次" / "用户发言 5 次"
matched = line.match(/用户发言\s*(\d+)\s*次/i);
if (matched) {
  userSpeakCount = parseInt(matched[1], 10);
  continue;
}
```

#### 2.2 扩展阶段结构
**文件**: `src/lib/gameEngine.ts`

```typescript
export interface ChapterRuntimeStage {
  id: string;
  label: string;
  kind: "scene" | "user";
  targetSummary: string;
  userNodeId: string | null;
  body: string;
  // 新增：用户发言次数要求
  userSpeakRequired?: number | null;
}
```

#### 2.3 运行时计数
**文件**: `src/modules/game-runtime/engines/ChapterProgressEngine.ts`

在 `ChapterProgressState` 中添加 `userSpeakCount` 字段：

```typescript
export interface ChapterProgressState {
  // ... 现有字段
  userSpeakCount?: number; // 当前事件/阶段用户发言次数
}
```

在 `applyAiEventProgressResolution` 中更新计数：

```typescript
// 如果是用户发言，增加计数
if (input.resolution.eventStatus === "waiting_input" && 
    latestMessage?.roleType === "player") {
  const newCount = (current.userSpeakCount || 0) + 1;
  setChapterProgressState(input.state, {
    userSpeakCount: newCount,
  });
}
```

#### 2.4 检测阶段完成条件
```typescript
// 检查用户发言次数是否达标
const currentStage = currentPhase?.stages?.[currentStageIndex];
if (currentStage?.userSpeakRequired && 
    (current.userSpeakCount || 0) >= currentStage.userSpeakRequired) {
  // 用户发言次数达标，推进到下一阶段
  isCurrentStageCompleted = true;
}
```

#### 2.5 重置计数
当进入新阶段时重置 `userSpeakCount`：

```typescript
// 在 stageAdvanced 时重置
setChapterProgressState(input.state, {
  stageIndex: nextStageIndex,
  userSpeakCount: 0, // 重置计数
  // ...
});
```

## 注意事项

1. **向后兼容**: `eventIndex`/`stageIndex` 为可选字段，不影响现有数据
2. **计数重置**: 切换事件/阶段时必须重置 `userSpeakCount`
3. **AI提示词**: 需要更新事件进度检测器的提示词，让AI理解计数型条件
