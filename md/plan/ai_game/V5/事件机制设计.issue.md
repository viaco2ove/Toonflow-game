# 问题点1
`- 编排,current_event: 1 ,石板硌着后背 → 天际裂缝 → 远处打斗声 → 用户发言`
缺乏进度到哪里的显示
可以添加进度显示
状态：空->i->s->f  
空: 未开始
i: 进行中
s: 完成
f: 失败
`- 编排,current_event: 1 ,[I]石板硌着后背 → []天际裂缝 → []远处打斗声 → []用户发言`
相对的。
- agent 也能感知到这个进度变化。
