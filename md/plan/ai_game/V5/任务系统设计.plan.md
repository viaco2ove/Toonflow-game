## 0. 现状分析

### 0.1 现有触发链路（**有缺陷**）

```
[用户输入] → [SessionService.addMessage]
              ↓
       [maybeResolveActiveFreeChapterTaskEvent]   ← ① 尝试结算已有任务
              ↓ (没有活跃任务 或 不需结算)
       [maybeActivateFreeChapterTaskEvent]      ← ② 尝试激活新任务
              ↓
       if (isFreeChapterRuntimeMode(chapter)) {  ← ★ 必须自由章节
         if (collectRecentFreeChapterTaskOptions().length > 0) {  ← ★ 旁白必须已推荐
           if (resolveSelectedFreeChapterTask(playerMsg, options)) { ← ★ 用户必须选了某项
             → AI 生成 task blueprint → 写 state.player.parameterCardJson.executing_task
           }
         }
       }
```

### 0.2 三大硬约束（用户当前遇到的空面板根因）

| # | 限制 | 后果 |
|---|------|------|
| 1 | `isFreeChapterRuntimeMode` 必须 true | 普通章节（含事件型章节）直接 return false |
| 2 | 旁白必须先输出了 `\d+\. 【分类】标题` 形式的推荐列表 | `collectRecentFreeChapterTaskOptions` 才有内容 |
| 3 | 用户必须**选择**了某项（不能仅"请求推荐"） | `resolveSelectedFreeChapterTask` 才返回非 null |

### 0.3 用户期望（来自任务系统设计.md L8-12）

> 1. 必须是自由章节？**不需要！**
> 2. 用户主动输入 `"#任务:xxxxx"` 触发
> 3. 意图识别为"创建任务"
> 4. 已处于任务中，创建新任务加入到 taskList，正在执行的任务不主动改变

## 1. 目标

| 目标 | 度量 |
|------|------|
| 任何章节都能创建任务 | `isFreeChapterRuntimeMode` 不再是门槛 |
| 用户输入即触发，无需旁白推荐 | 移除对"最近旁白推荐列表"的依赖 |
| 命令 + AI 兜底双路径 | `#任务:xxx` 命令 100% 命中；自然语言兜底 |
| 与现有 miniGame 系统无缝集成 | 复用 task rulebook + parameter card UI |

## 3. 详细设计

### 3.1 触发层 — 命令前缀

**新增文件**：`src/modules/game-runtime/agents/intentAnalyzer/index.ts`

```typescript
// ===== 规则预检 (fast path) =====
const COMMAND_PATTERNS: Record<CommandIntent, RegExp> = {
  create_task: /^\s*#\s*(?:任务|开任务|新建任务|task|mission)\s*[:：\-]?\s*(.+)$/i,
  exit_task:   /^\s*#\s*(退出任务|exit\s*task|abort\s*task)\s*$/i,
  query_progress: /^\s*#\s*(任务进度|进度|status)\s*$/i,
};

function detectCommand(message: string): { intent: Intent; params: any } | null {
  for (const [intent, pattern] of Object.entries(COMMAND_PATTERNS)) {
    const match = message.match(pattern);
    if (match) {
      switch (intent) {
        case 'create_task':
          return {
            intent: 'create_task',
            confidence: 1.0,
            params: { task_description: match[1]?.trim() || '' }
          };
        case 'exit_task':
          return { intent: 'exit_task', confidence: 1.0, params: {} };
        case 'query_progress':
          return { intent: 'query_progress', confidence: 1.0, params: {} };
      }
    }
  }
  return null;
}
```

**支持的命令格式**（大小写不敏感）：

| 命令 | 含义 | 备注 |
|------|------|------|
| `#任务:到村长家偷鸡` | 创建任务，描述"到村长家偷鸡" | 主推格式 |
| `#任务 到村长家偷鸡` | 同上 | 兼容 |
| `#开任务:探索古墓` | 同上 | 别名 |
| `#task:xxx` | 同上 | 英文别名 |
| `#退出任务` | 退出当前任务 | |
| `#任务进度` | 查询当前任务进度 | |

### 3.2 兜底层 — AI 意图分析

```typescript
// ===== AI 分类 (slow path) =====
import { m3eSmallClassify } from '@/lib/ai/m3eIntentClassifier';

async function aiClassifyIntent(ctx: IntentContext): Promise<IntentResult> {
  const prompt = buildIntentPrompt(ctx);  // 复用意图分析师_prompt.md
  // 模型选择优先级:  m3e-small (本地 10ms) → Qwen2.5-1.5B → GPT-4 mini
  const result = await m3eSmallClassify(prompt, ['create_task', 'exit_task', 'query_progress', 'game_action', 'normal_dialog']);
  return result;
}
```

**降级链**：
1. **m3e-small 嵌入相似度**（~10ms，CPU 即可） — 主路径
2. **Qwen2.5-1.5B 本地**（~100ms，CPU 即可） — 备用
3. **Qwen2.5-3B 在线**（~300ms，需 GPU） — 二次降级
4. **默认 normal_dialog**（0ms） — 终极降级

**置信度阈值**：≥ 0.7 才采纳 AI 分类，否则降级到 normal_dialog。

### 3.3 任务创建流程（重写 `handleCreateTask`）

**文件**：`src/modules/game-runtime/engines/MiniGameController.ts`

```typescript
async function handleCreateTask(input: {
  userId: number;
  world: any;
  chapter: any;
  state: JsonRecord;
  recentMessages: any[];
  taskDescription: string;
}): Promise<MiniGameTurnResult> {
  // 1. 并发任务处理：已有活跃任务 → 加入列表，不替换
  const existingTask = readExecutingTask(input.state);
  const taskList = readTaskList(input.state);
  
  // 2. 调 AI 生成 task blueprint（不依赖 isFreeChapterRuntimeMode）
  const blueprint = await generateFreeChapterTaskBlueprintByAi({
    userId: input.userId,
    world: input.world,
    chapter: input.chapter,
    state: input.state,
    userRequest: input.taskDescription,  // ★ 新增：直接传用户描述，不再依赖 options
  }) || buildTaskBlueprintFromUserInput(input.taskDescription, input.chapter);
  
  // 3. 写 state
  const newTask = {
    task_id: uuid(),
    title: blueprint.taskTitle,
    category: blueprint.category || "自由任务",
    objective: blueprint.objective,
    process: blueprint.process || [],
    successConditions: blueprint.successConditions || [],
    failureConditions: blueprint.failureConditions || [],
    reward: blueprint.reward || { exp: 50, items: [] },
    status: "doing",
    createdAt: Date.now(),
  };
  
  // 4. 写入 executing_task 和 taskList
  applyTaskCreatedToState(input.state, {
    executingTask: newTask,
    taskList: [...taskList, newTask],
  });
  
  // 5. 初始化 miniGame session (gameType="task")
  const session = setupTaskMiniGameSession(input.sessionId, newTask, "create_task");
  
  return {
    narration: `任务【${newTask.title}】已开启。目标：${newTask.objective}。直接输入行动推进任务；输入 #退出 可放弃。`,
    resultTags: ['task_created'],
    eventType: 'on_mini_game_start',
    session,
  };
}
```

### 3.5 任务列表（taskList）存储

**Schema 扩展**：

```typescript
// state.player.parameterCardJson
{
  // 现有字段
  hp: 100, mp: 50, exp: 0, level: 1,
  // ...
  
  // ★ 新增
  executing_task: FreeTask | null,    // 当前正在执行的任务（互斥，1 个）
  taskList: FreeTask[],                // 所有任务的列表（历史 + 进行中 + 已完成）
  activeTaskId: string | null,         // executing_task 的 task_id
}
```

**状态机**：
```
                    create_task                  success/fail/abort
[空] ───────────────────────→ [executing=taskA, list=[taskA]] ──────────────→ [executing=null, list=[taskA(done)]]
   │                                     │                                    │
   │   create_task (并发)                │ exit_task (无任务时无操作)             │
   │                                     ↓                                    ↓
   └────────────────────────→ [executing=taskA, list=[taskA, taskB]]
                                                                                    ↑
                                                                       switchTask   │
                                                                                    │
                              [executing=taskA, list=[taskA, taskB, taskC]]  ←──────┘
                                       │
                                  switchTask(taskB)
                                       ↓
                              [executing=taskB, list=[taskA, taskB, taskC]]
```

**新命令**：
- `#切换任务 <id>` — 把 taskList 中已完成/失败的任务切换成 executing_task
- `#任务列表` — 查询 taskList

## 7. 风险与降级

| 风险 | 降级策略 |
|------|---------|
| AI 误识别（自然语言被误判为 create_task） | 置信度 < 0.7 → normal_dialog；用户可在 miniGame 面板里 `#退出` |
| m3e-small 模型未部署 | 自动降级到 Qwen2.5-1.5B → GPT-4 mini → normal_dialog |
| 任务蓝图生成失败 | 用 `buildTaskBlueprintFromUserInput` 兜底（直接用用户输入当 title 和 objective） |
| 任务列表超长（>20 个） | 只保留最近 20 个 + executing_task，旧的归档到 state.taskHistory（独立字段） |
| 并发 `#任务:xxx` 同时触发 | 加 inflight 锁：同一 sessionId 5s 内只处理第一个 |
