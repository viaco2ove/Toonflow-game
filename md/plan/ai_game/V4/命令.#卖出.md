# 增加命令 #卖出 xxx .

## 功能描述

玩家在游戏进行中可以输入 `#卖出 xxx` 命令，将背包中的物品出售换钱。由大模型智能解析：

- 匹配玩家想卖的物品
- 确定出售数量
- 计算总价
- 生成交易旁白

## 使用示例

```
#卖出 青鱼          -- 卖出指定物品
#卖出 全部鱼        -- 卖出所有鱼
#卖出 全部          -- 卖出背包所有物品
#卖出 稀有鱼 3条    -- 出售3条稀有鱼
```

## 物品数据结构

物品在 `state.inventory` 中存储为对象数组，每项结构：

```typescript
interface InventoryItem {
  name: string;      // 物品名称，如 "青鱼"
  kind?: string;    // 种类，如 "fish", "ore", "treasure", "loot", "pill"
  amount?: number;   // 数量（可选，默认1）
  rarity?: string;   // 稀有度（可选），如 "normal", "rare"
}
```

## 定价规则（供AI参考）

| 种类 (kind) | 单价（金币） |
|------------|-------------|
| fish (鱼)  | 稀有度 rare=5, normal=2 |
| ore (矿石) | amount × 1 |
| treasure (宝物) | 10 |
| loot (战利品) | 3 |
| pill (丹药) | 5 |
| 其他 | 1 |

## 实现方案

### 1. 命令检测

在 `MiniGameController.ts` 中新增命令检测函数：

```typescript
function isSellCommand(input: string): boolean {
  const text = scalarText(input);
  if (!text.startsWith("#卖出") && !text.startsWith("#卖")) return false;
  return true;
}
```

### 5. MiniGameController 集成

在 `agentMain` 中 `#卖出` 命令拦截点：

```typescript
// 处理 #卖出 命令（全局命令，不限于小游戏内）
if (isSellCommand(input.playerMessage)) {
  const inventory = asArray<JsonRecord>(state.inventory);
  const result = await resolveSellIntent(
    input.playerMessage,
    inventory,
    SELL_PRICING_RULES,
  );

  if (!result) {
    return buildSimpleNarrationResult(
      "出售解析失败，请检查输入或背包是否有该物品。",
      ctx
    );
  }

  if (result.sellItems.length === 0) {
    return buildSimpleNarrationResult(
      "背包里没有符合条件的物品可以出售。",
      ctx
    );
  }

  // 记录日志
  logMiniGameAction({
    normalizedInput: normalizeMiniGameActionText(input.playerMessage),
    controlAction: "sell",
    intercepted: true,
    resultTags: ["sell", `sold_${result.sellItems.length}_items`],
  });

  // 从背包移除已卖物品
  const soldNames = result.sellItems.map((item) => item.name);
  removeInventoryEntriesByNames(state, soldNames);

  // 增加金币
  const card = createPlayerParameterCard(state);
  card.money = Number(card.money || 0) + result.totalMoney;
  asRecord(state.player).parameterCardJson = card;

  // 记录记忆
  const memoryAdd = result.sellItems.map(
    (item) => `出售：${item.name}×${item.quantity}（+${item.subtotal}金）`
  );

  return {
    intercepted: true,
    message: {
      role: narratorName,
      roleType: "narrator",
      eventType: "on_inventory_sell",
      content: result.narration,
    },
    writeback: {
      inventoryRemoveNames: soldNames,
      playerParameterPatch: { money: result.totalMoney },
      memoryAdd,
    },
    pendingNarrativePlan: buildMiniGameNarrativePlan(
      "物品出售结算",
      result.narration,
      true,
      narratorName,
      playerName,
      "on_inventory_sell",
    ),
  };
}
```

## 注意事项

1. `#卖出` 是全局命令，不需要在特定小游戏内才能使用
2. AI负责智能匹配：玩家说"全部鱼"时会模糊匹配所有相关物品
3. AI负责确定数量：可以指定"卖出3条"这样的数量
4. AI负责计算总价：按定价规则自动计算
5. AI负责生成旁白：返回符合游戏风格的交易叙述
6. 系统层验证：确保AI返回的物品确实在背包中存在，防止作弊
