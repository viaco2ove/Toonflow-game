# h5 分析：挖矿奖励没有放入用户背包，且结算时无奖励说明

## 问题描述

1. **物品没有放入背包**：用户挖矿后，获得的矿物/宝物没有出现在用户背包/物品栏中
2. **结算时无奖励说明**：撤离/采尽时，AI 叙述不提及具体获得了什么矿物和宝物

## 根因分析

### 根因 1：正常挖矿时 `bag_load` 不转换为背包物品

**问题代码**：`miningStep` 中 `excavate`/`careful_excavate` 分支（line ~4017-4030）：

```typescript
if (actionId === "excavate") {
  add("vein_hp", -(20 + bonus), 0, 100);
  add("player_stamina", -15, 0, 100);
  add("danger", 10, 0, 100);
  add("bag_load", 12, 0, 100);  // ← 只增加了 bag_load，没有调用 resolveMiningRewards
  hidden.weakness_point = false;
}
```

**影响**：每挖一次，`bag_load` 数值增加（如从 10→22→34），但 `inventoryAdd` **不会**通过 `writeback` 进 `state.inventory`。物品只是"负重"数字，没有真正进背包。

**只在撤离/采尽时才调用 `resolveMiningRewards`**（line ~4045-4085），此时才设置 `inventoryAdd` → `writeback`。

**结果**：如果玩家一直挖矿不撤离（不触发 `leave` 或坍塌），则 `bag_load` 一直累加但永远不转成背包物品，最终撤离时一次性全部丢失（因为之前的 `bag_load` 早已在状态中，但没有分批写入）。

### 根因 2：`pendingNarrativePlan` 不携带奖励元数据

**问题代码**：`buildMiniGameNarrativePlan` 只携带叙事信息：

```typescript
return {
  role: narratorName,
  roleType: "narrator",
  motive: motiveText,
  presetContent: narration,  // 纯文本，如"矿脉剩余 88，危险度 22，负重 10。"
  awaitUser: true,
  // ... 没有 rewardSummary / writeback / itemNames
};
```

**AI 叙述丢失奖励信息**：
- `presetContent` 只有状态播报（"矿脉剩余 X，危险度 Y，负重 Z"）
- AI 生成叙述时不会提及具体获得了什么矿物、稀有物品
- 即使 `step.rewardSummary` 存在（撤离/采尽时），也没有传递给 `pendingNarrativePlan`

**前端无法展示奖励**：`pendingNarrativePlan` 的返回结构里没有 `rewardSummary`、`itemNames`、`rareItem` 等字段，前端无法在对话中展示奖励面板。

### 根因 3：`applyMiniGameWriteback` 确实被调用了（代码逻辑正确）

从代码看，`applyMiniGameWriteback(state, step.writeback)` 在 `handleMiniGameTurn` 的 line 5723-5725 被调用：
```typescript
if (step.writeback && Object.keys(step.writeback).length) {
  root.writeback = step.writeback;
  applyMiniGameWriteback(state, step.writeback);  // 确实会修改 state.inventory
}
```

但问题是：**`step.writeback` 在正常挖矿时为空**，只在撤离/采尽时才有值。

## 修复方案

### 方案 1：每次挖矿动作都将 `bag_load` 转换为背包物品（进行中奖励）

**修改位置**：`miningStep` 的 `excavate`/`careful_excavate` 分支

**思路**：每次开采后，将 `bag_load` 按比例转换为 `inventoryAdd` 并通过 `writeback` 写入 `state.inventory`：

```typescript
if (actionId === "excavate") {
  add("vein_hp", -(20 + bonus), 0, 100);
  add("player_stamina", -15, 0, 100);
  add("danger", 10, 0, 100);
  const bagDelta = 12;
  add("bag_load", bagDelta, 0, 100);
  // 将 bag_load 增量转换为背包物品
  const targetOre = scalarText(publicState.target_mineral) || "矿石";
  const oreAmount = Math.floor(bagDelta * 0.8);  // 按 80% 折算
  if (oreAmount > 0) {
    const currentInventory = asArray<any>(state.inventory || []);
    state.inventory = [...currentInventory, { kind: "ore", name: targetOre, amount: oreAmount }];
  }
  hidden.weakness_point = false;
}
```

**注意**：这会修改 `state.inventory`，需要确保 `applyMiniGameWriteback` 也能正确处理（或直接在这里写入 `state.inventory`）。

### 方案 2：`pendingNarrativePlan` 携带奖励元数据

**修改位置**：`buildMiniGameNarrativePlan` 或在返回时将 `step.rewardSummary` 合并进去

**思路**：`pendingNarrativePlan` 增加可选的奖励字段：

```typescript
return {
  role: narratorName,
  roleType: "narrator",
  motive: motiveText,
  presetContent: narration,
  awaitUser: true,
  nextRole: playerName,
  nextRoleType: "player",
  source: "rule",
  eventType,
  eventAdjustMode: "keep",
  eventStatus: isFinished ? "finished" : "active",
  nextNarrativePlan: null,
  // 新增：奖励信息（供前端展示奖励面板）
  rewardSummary: step.rewardSummary || null,
  itemNames: step.itemNames || null,
  writeback: step.writeback || null,
};
```

同时在 `addSessionMessage` 中，当 `miniGameResult.pendingNarrativePlan` 存在时，将其携带的奖励信息写入 `state.pendingNarrativePlan`。

### 方案 3：AI 叙述 prompt 包含奖励信息

**修改位置**：`pendingNarrativePlan` 的 `presetContent` 中包含奖励描述

**思路**：在 `miningStep` 返回的 `narration` 中，除了状态播报，还应包含奖励描述：

```typescript
// 在撤离/采尽时
const oreAmount = Math.max(1, Math.floor(Number(publicState.bag_load || 0) / 10));
const rewards = resolveMiningRewards(session, oreAmount);
const narration = `你选择及时撤离，把当前矿物安全带离了矿区。
获得：${rewards.itemNames.join("、")}。${rewards.rareItem ? `额外挖出了 ${rewards.rareItem}！` : ""}`;
```

这样 `presetContent` 就包含了奖励信息，AI 叙述会提及具体奖励。

## 建议修复顺序

1. **先做方案 1**（每次挖矿都给物品，保证奖励不丢失）
2. **再合并方案 2+3**（让结算时 AI 叙述包含奖励，且前端能展示奖励面板）

## 验证要点

### 验证方案 1
1. 挖矿 3 次（不开采/精挖）
2. 查看 `state.inventory` 是否有 3 次物品增加
3. 不撤离，直接看背包是否有积累的矿物

### 验证方案 2+3
1. 输入"撤离"
2. 观察 AI 叙述是否提及"获得铁矿×X"和稀有物品
3. 观察前端是否展示奖励面板（物品名称、数量）
